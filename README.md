# 刹那のぷゆり

匿名SNS **kusa** に iframe 組み込みで提供する、リアルタイム1対1の早押し対戦。
🥺（コミュニティ内の呼称「ぷゆゆ」）を使い、合図が出たら先にタップした方が勝ち。合図前のタップはフライング負け。

1試合は数秒〜十数秒。シンプルさと、安全性を説明しやすい構成を重視する。
